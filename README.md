# 灰烬王冠 · 拾灰人纪事

> 三十年前，钟楼敲到第十三响，霍洛城就再没有声音。
> 教廷把它记作疫病，卷宗上只留了一行字：**「无生者。」**

一个西幻黑暗哥特风格的**长篇小说式文字 MUD**。纯前端、零依赖、零构建，双击 `index.html` 即玩。

## 玩什么

你是**凯尔·凡恩**，灰袍兄弟会的拾灰人——替死人收尸，也替死人跑腿。

有人给你一封没有署名的信、半枚银币，叫你去霍洛城，把一件不该被找回来的东西带回来。

全篇分**四卷**：鸦渡的河、灰门的城、钟楼的井、灰烬的冠。十九个地方，从河岸一路走到钟底那口池子。

城里有尸犬、石像鬼、稻草人、白狼、墓中尸、骷髅骑士、唱诗者、撞钟人、守墓人。最深处坐着**灰烬圣女**，她梳了三十年的头，就等一个人看。

**六个结局**：黎明、加冕、远路、归还、王冠、殉道。都是你自己选出来的。

## 怎么玩

在底部输入框敲命令，回车。方向键翻历史，`Tab` 补全，点「出路」按钮也能走。

| 指令 | 作用 |
| --- | --- |
| `看` / `look` | 看看四周。**很多地方要细看**：`看 城徽`、`看 木柜`、`看 白布` |
| `走 北` / `n` | 朝某方向走（`n s e w u d` 或 `北南东西上下`） |
| `拿 剑` / `take` | 拾起地上的东西 |
| `用 药水` / `use` | 喝药；`读 信` 可展信 |
| `装备 剑` / `穿 袍` | 换兵器、护甲与戒指 |
| `打 尸犬` / `attack` | 动手 |
| `说话 老人` / `talk` | 与人对谈。**同一个人可以谈四次**，越往后越接近真相 |
| `买` / `卖` / `list` | 行商处交易（先 `说话 吉德`） |
| `休息` / `rest` | 只在小堂可行，回满气血法力；**铁匠铺可以卖戒指换属性** |
| `背包` `属性` `技能` `任务` | 查看自身 |
| `地图` `存档` `读档` | 地图与存读 |

**战斗**是回合制：`a` 普攻、`1`–`9` 出招、`用 药水`、`f` 逃。

九式技艺：重劈、祷告、侧步、火球术、治愈之手、净化、审判、圣光，以及升阶自动获得的那一式。
石像鬼的毒、白骨戒的法力、锁甲的防御、磨刀石的锻造加成——打法不止一种。

## 内容

- **4 卷 19 个房间**，含带锁的井门、必须点火的暗室
- **10 种敌人 + 1 个 Boss**，四个房间的怪物会重新长出来
- **6 个可交谈的角色**，每人四段对话，越谈越深
- **4 条支线**：三具尸体、格伦的锤子、最后一杯酒、折掉的笔
- **9 式技艺、25 件物品、6 个结局**（其中一个要戴着骨冠离开）
- 剧情里藏了四条线索，凑齐了才答得出最后那句话
- 存档走 `localStorage`，关掉浏览器也在

        ├── world.js      书名、卷目、序章、境界

约 3700 行，没有框架，没有 npm，没有构建步骤。

## 技术笔记

- **不用 ES module**：`file://` 下 `type="module"` 会被 CORS 拦死，普通 `<script src>` 才能双击打开。所以脚本靠 `window.DATA` / `window.Game` 通信，`data/` 下的五个文件按顺序加载即可。
- **内容全在 `data/`**：加一个房间、一件物品、一个敌人、一段对话、一条支线，只改对应文件。`engine.js` 不认具体名字，只认结构。
- **中文宽度对齐**：日志里的地图与表格用 CSS Grid 排版，不靠空格凑——等宽中文字形宽度未必是半角的整两倍。
- **事件流单一出口**：引擎产出事件数组（place/desc/say/book/combat/item…），界面只负责把它渲染成字。
