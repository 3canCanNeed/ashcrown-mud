# 十三响 · 霍洛城的一小时

> 钟一天敲十二下。第十三下是多的那一下。
> 那一小时到现在还没过完。

一个西幻黑暗哥特风格的**文字 MUD**，内核是**时间循环**：你被困在霍洛城死亡前的同一个小时里，一夜一夜地重来。纯前端、零依赖、零构建，双击 `index.html` 即玩。

## 玩什么

三十年前的七月十九日，霍洛城的钟敲到第十三响，全城一百三十七口人卡在自己死前最后做的那件事里，一遍一遍地重复，谁都不觉得奇怪。

你是那个被抱出去的孩子——裹在羊毛里，从灰门底下推出去。今年你三十岁，回来了。

你不是来查真相的。你是来把这一小时**过完**的。

### 循环怎么转

- 一夜 = **22:00 → 24:00**，每个动作一分钟，到点自动翻夜
- 死了也翻夜，不扣经验、不扣钱——只是又一夜
- 想快点换一夜，就敲 `listen`（听钟）
- 翻夜会**保留**你记得的一切（线索、背包、说过的话），**重置**身体、时间、城里的活物
- 每熬过两夜，城市会对你敞开得更深一点

命只有一条，但夜有很多条。

## 怎么玩

在底部输入框敲命令，回车。方向键翻历史，`Tab` 补全，点「出路」按钮也能走。

| 指令 | 作用 |
| --- | --- |
| `看` / `look` | 看四周；`看 城徽` 可细看某物 |
| `走 北` / `n` | 朝某方向走（`n s e w u d` 或 `北南东西上下`） |
| `拿 剑` / `take` | 拾起地上的东西 |
| `用 药水` / `use` | 喝药；`读 信` 可展信 |
| `装备 剑` / `穿 袍` | 换兵器与护甲 |
| `打 尸犬` / `attack` | 动手 |
| `说话 老人` / `talk` | 与人对谈，多谈几次话会不一样 |
| `买` / `卖` / `list` | 行商处交易 |
| `休息` / `rest` | 只在圣阿黛拉小堂可行，回满气血法力 |
| `听钟` / `listen` | 熬过一夜——睡过去，让这一小时重新开始 |
| `背包` `属性` `技能` `任务` | 查看自身 |
| `地图` `存档` `读档` | 地图与存读 |

**战斗**是回合制：`a` 普攻、`1`–`5` 出招、`用 药水`、`f` 逃。

## 内容

- **19 个房间**，四卷解锁（第一夜·灰门 → 第三夜·城中 → 第五夜·钟楼 → 第七夜·十二响）
- **6 个可交谈的人**，每个人都在重复自己做不完的那件事
- **10 种怪物**，都是那一小时里卡住的东西
- **9 式技艺**、8 件装备、8 种消耗品
- **4 条支线** + 4 条主线线索
- **6 个结局**，其中三个需要你先解开线索才说得出口
- 存档走 `localStorage`，关掉浏览器也在

## 技术笔记

- **不用 ES module**：`file://` 下 `type="module"` 会被 CORS 拦死，普通 `<script src>` 才能双击打开。所以脚本靠 `window.DATA` / `window.Game` 通信。
- **数据与引擎彻底分开**：故事全在 `js/data/` 五个文件里，改剧情不用碰引擎。
- **时间即状态**：`S.clock` 从 0 数到 119，到 120 就 `endNight()`——翻夜会重置身体与城里的活物，但留下记忆。这是整个游戏唯一的核心机制。
- **中文宽度对齐**：日志里的地图与表格用 CSS Grid 排版，不靠空格凑。
